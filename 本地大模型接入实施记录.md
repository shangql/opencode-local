# opencode 接入本地大模型功能实施记录

## 项目背景

- **本地大模型信息**：
  - Base URL: `http://192.168.102.99:8000/v1/chat/completions`
  - API Key: `sk-token1`
  - 模型类型: Qwen 系列模型
  - 模型数量: 20+ 个不同规格的 Qwen 模型

- **目标**：在 opencode 项目中增加接入本地大模型的功能，使其能够利用本地部署的 Qwen 模型进行编程辅助。

## 技术分析

### 现有架构优势

1. **内置 OpenAI 兼容 API 支持**：
   - opencode 已集成 `@ai-sdk/openai-compatible` 库
   - 支持自定义 baseURL 和 API Key
   - 已有 GitHub Copilot 等类似实现

2. **配置驱动架构**：
   - 支持通过 `opencode.jsonc` 配置文件定义 provider
   - 支持环境变量配置
   - 模块化的 provider 注册机制

3. **完善的模型管理**：
   - 支持模型列表查询 (`opencode models`)
   - 支持模型选择和切换
   - 统一的 API 调用接口

### 技术方案

**核心思路**：利用现有的 OpenAI 兼容 API 支持，创建自定义 provider 配置来接入本地大模型，无需大量修改源代码。

### 阶段二：核心实现

#### 2.1 创建本地模型 provider 模块

创建了新的 provider 模块：`packages/opencode/src/provider/sdk/local-model/`

**文件结构**：

```
packages/opencode/src/provider/sdk/local-model/
├── src/
│   ├── local-model-provider.ts  # Provider 核心实现
│   └── index.ts               # 导出接口
```

**local-model-provider.ts 实现**：

```typescript
import type { LanguageModelV2 } from "@ai-sdk/provider"
import { OpenAICompatibleChatLanguageModel } from "@ai-sdk/openai-compatible"
import { type FetchFunction, withoutTrailingSlash, withUserAgentSuffix } from "@ai-sdk/provider-utils"

const VERSION = "1.0.0"

export type LocalModelId = string

export interface LocalModelProviderSettings {
  apiKey?: string
  baseURL?: string
  name?: string
  headers?: Record<string, string>
  fetch?: FetchFunction
}

export interface LocalModelProvider {
  (modelId: LocalModelId): LanguageModelV2
  chat(modelId: LocalModelId): LanguageModelV2
  responses(modelId: LocalModelId): LanguageModelV2
  languageModel(modelId: LocalModelId): LanguageModelV2
}

export function createLocalModel(options: LocalModelProviderSettings = {}): LocalModelProvider {
  let baseURL = options.baseURL ?? "http://localhost:8000/v1"
  if (baseURL.includes("/chat/completions")) {
    baseURL = baseURL.replace("/chat/completions", "")
  }
  baseURL = withoutTrailingSlash(baseURL)

  if (!baseURL) {
    throw new Error("baseURL is required")
  }

  const headers = {
    ...(options.apiKey && { Authorization: `Bearer ${options.apiKey}` }),
    "Content-Type": "application/json",
    ...options.headers,
  }

  const getHeaders = () => withUserAgentSuffix(headers, `ai-sdk/local-model/${VERSION}`)

  const createChatModel = (modelId: LocalModelId) => {
    return new OpenAICompatibleChatLanguageModel(modelId, {
      provider: `${options.name ?? "local-model"}.chat`,
      headers: getHeaders,
      url: ({ path }) => `${baseURL}${path}`,
      fetch: options.fetch,
    })
  }

  const createResponsesModel = (modelId: LocalModelId) => {
    return new OpenAICompatibleChatLanguageModel(modelId, {
      provider: `${options.name ?? "local-model"}.responses`,
      headers: getHeaders,
      url: ({ path }) => `${baseURL}${path}`,
      fetch: options.fetch,
    })
  }

  const createLanguageModel = (modelId: LocalModelId) => createChatModel(modelId)

  const provider = function (modelId: LocalModelId) {
    return createChatModel(modelId)
  }

  provider.languageModel = createLanguageModel
  provider.chat = createChatModel
  provider.responses = createResponsesModel

  return provider as LocalModelProvider
}

export const localModel = createLocalModel()
```

**index.ts 导出**：

```typescript

```

**步骤 3**：添加到 CUSTOM_LOADERS

```typescript
const CUSTOM_LOADERS: Record<string, CustomLoader> = {
  // ... 其他 loaders ...

  "local-model": async (input) => {
    const config = await Config.get()
    const providerConfig = config.provider?.["local-model"]
    const baseURL = providerConfig?.options?.baseURL ?? Env.get("LOCAL_MODEL_BASE_URL")
    const apiKey = providerConfig?.options?.apiKey ?? Env.get("LOCAL_MODEL_API_KEY")

    const autoload = !!baseURL

    async function getModel(sdk: any, modelID: string) {
      return sdk.chat(modelID)
    }

    const fetchLocalModels = async () => {
      if (!baseURL) return []
      try {
        const url = baseURL.endsWith("/v1") ? baseURL.replace("/v1", "/v1/models") : `${baseURL}/v1/models`
        const response = await fetch(url, {
          headers: {
            ...(apiKey && { Authorization: `Bearer ${apiKey}` }),
            "Content-Type": "application/json",
          },
          signal: AbortSignal.timeout(10 * 1000),
        })
        if (!response.ok) return []
        const data = await response.json()
        return data.data || []
      } catch (e) {
        log.error("Failed to fetch local models", { error: e })
        return []
      }
    }

    if (autoload) {
      const localModels = await fetchLocalModels()
      for (const model of localModels) {
        if (!input.models[model.id]) {
          const modelId = model.id
          const parsedModel: any = {
            id: modelId,
            name: modelId,
            providerID: "local-model",
            api: {
              id: modelId,
              npm: "@ai-sdk/local-model",
              url: baseURL,
            },
            status: "active",
            capabilities: {
              temperature: true,
              reasoning: true,
              attachment: true,
              toolcall: true,
              input: {
                text: true,
                audio: false,
                image: false,
                video: false,
                pdf: false,
              },
              output: {
                text: true,
                audio: false,
                image: false,
                video: false,
                pdf: false,
              },
              interleaved: false,
            },
            cost: {
              input: 0,
              output: 0,
              cache: {
                read: 0,
                write: 0,
              },
            },
            limit: {
              context: model.max_tokens || 131072,
              output: 4096,
            },
            options: {},
            headers: {},
            family: "",
            release_date: new Date().toISOString(),
            variants: {},
          }
          input.models[modelId] = parsedModel
        }
      }
    }

    return {
      autoload,
      options: {
        baseURL,
        apiKey,
      },
      getModel,
    }
  },
}
```

**关键特性**：

- 自动从本地 API `/v1/models` 端点获取模型列表
- 支持环境变量配置（LOCAL_MODEL_API_KEY, LOCAL_MODEL_BASE_URL）
- 自动检测和注册所有可用模型
- 设置合理的默认参数（context: 131072, output: 4096）

## 技术细节

### Provider 架构

```
opencode
├── BUNDLED_PROVIDERS (内置 providers)

```

### 自动模型发现流程

1. **初始化阶段**：
   - 读取配置文件中的 `local-model` provider
   - 检查 baseURL 是否配置

2. **模型发现**：
   - 调用 `fetchLocalModels()` 函数
   - 请求 `{baseURL}/v1/models` 端点
   - 解析返回的模型列表

3. **模型注册**：
   - 遍历发现的每个模型
   - 创建标准的 Model 对象
   - 设置合理的默认参数（capabilities, cost, limit）
   - 添加到 provider 的 models 字典

4. **模型使用**：
   - 用户指定模型 ID 时
   - `getModel()` 函数调用 `sdk.chat(modelID)`
   - 创建对应的语言模型实例

### 性能优化

#### 超时设置

由于本地模型推理速度较慢，需要设置适当的超时时间：

```jsonc
{
  "provider": {
    "local-model": {
      "options": {
        "timeout": 120000, // 120 秒
      },
    },
  },
}
```

#### 请求优化

- **避免频繁的小请求**：尽量合并多个小任务为一个大请求
- **利用上下文窗口**：最大 131072 tokens，可以处理大量代码
- **设置合理的 max_tokens**：避免生成过多不必要的内容

## 故障排除

### 常见问题

#### 1. 连接失败

**症状**：

```
Error: Provider not found: local-qwen
```

**解决方法**：

- 检查本地大模型服务是否运行
- 验证 baseURL 是否正确
- 确认网络连接：`ping 192.168.102.99`

#### 2. 模型未找到

**症状**：

```
Error: Model not found: local-qwen/unknown-model
```

**解决方法**：

- 运行 `opencode models local-qwen` 查看可用模型
- 检查模型 ID 是否正确
- 确认模型是否在本地服务中可用

#### 3. 超时错误

**症状**：

```
Error: Request timed out after 60000ms
```

**解决方法**：

- 在配置文件中增加 timeout 值
- 检查本地模型服务的性能
- 考虑使用更小的模型

#### 4. API 错误

**症状**：

```
Error: 401 Unauthorized
```

**解决方法**：

- 验证 API Key 是否正确
- 检查授权格式：`Bearer sk-token1`
- 查看本地服务的日志
